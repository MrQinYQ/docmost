# 移除同步锁，冲突时提示

按用户明确选择：删除本地操作票号、页面租约、OpenViking 根目录租约及根目录任务互斥，不再获取、等待或依赖任何旧锁。MCP 生命周期和已启用的 MD 监听保持不变，不新增服务。保留原有绑定、凭据、目的地、快照和未确认任务。

同步前读取最新账本，文件仍使用私有权限与原子替换；此处检查不能替代原子 CAS，只报告实际检测到的变化。发现账本已变化时返回 `CONFLICT`，保留另一方记录。Docmost MD/Git 上传继续使用服务端 `expectedRevision` 条件写入，网页或分支变化暂停，需用户明确选择后解决。同一连接的异步任务按原调用顺序执行，这是内存调度，不产生跨进程锁或忙状态。

OpenViking 取消整棵根目录的独占 gate，其他页面的任务或历史记录不会阻止本页。每页仍保存自己的 taskId、原文哈希和不确定结果，读回核对本页任务，不重放未知写入；远端原文变化返回冲突并停止。服务端自身的忙/冲突原样作为独立知识库失败报告，不自动重复 Docmost 写入。

登录文件也不生成 `.lock`，新会话通过完整临时文件的排他发布避免覆盖已有会话。过期记录和登出保留身份核对。普通 `update_page` 没有原子条件写接口，OpenViking HTTP 接口也没有通用 CAS；不能声称移除本地锁后能检测所有同时发生的远端写入。使用前后校验报告可检测的冲突。

不再修补租约超时或引入另一种锁。仅在当前工作区修改；更新本机实际使用的安装包和 Skill 并备份。旧锁不再参与运行；清理时仅移除锁文件，不删除账本或未知任务。不自动提交或推送，本轮以实现和验收为范围。

审阅补充：重复登记标记为可解绑的冲突，不阻塞其他页面；查询归属不更新写入基线；内容快照不做自动回收，避免并发误删。会话使用私有代际副本及精确撤销标记抵御迟到的旧文件删除，无锁无等待。祖先索引响应丢失时不能通过其他页面新任务推断成功，保留 OV_UNCONFIRMED。
